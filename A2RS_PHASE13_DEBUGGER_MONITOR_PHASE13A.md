# A2RS Phase 13-A Debugger / Monitor

## Added

- Ctrl+F8: runtime debug overlay ON/OFF
- Ctrl+F10: pause / resume
- Ctrl+F11: single-instruction step while paused

## Overlay

Displays:
- PC / opcode
- A / X / Y / SP / flags
- total cycles
- scanline / scanline cycle / HBL / VBL
- floating bus address/value
- current drive, track, half-track, phase, byte position
- motor / write status

## Notes

- Existing screenshot on F10 remains available; the debugger uses Ctrl+F10.
- Existing debugger panel on F11 remains available; single-step uses Ctrl+F11.
- Existing slot select on F8 remains available; overlay uses Ctrl+F8.
